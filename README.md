## About Me

I am a software engineer who builds dependable products across backend services, applied AI, full-stack applications, and the infrastructure that supports them. I enjoy turning ideas into production systems—from API and data design to user-facing features, automated delivery, and reliable operations.

- 💻 I work with Python, TypeScript, Go, APIs, event-driven systems, and modern web applications.
- 🧠 I enjoy building AI-powered features, agentic workflows, and data-intensive services.
- ⚙️ I use DevOps and cloud practices to make software repeatable, observable, and easier to operate.
- 🌱 I am continuously improving my system-design, performance, reliability, and platform-engineering skills.
- 🤝 Open to collaborating on software engineering, backend, AI, full-stack, and DevOps projects.
